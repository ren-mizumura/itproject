# **要件定義書：モンスターハンター特化型 知識・TA共有掲示板（仮）**

## **1\. プロジェクト概要**

### **1.1 開発背景と目的**

『モンスターハンター』シリーズにおいて、プレイヤーがタイムアタック（TA）を縮めるためのテクニックや、各武器種のフレーム単位・位置調整の小技などは、SNS上で日々検証・議論されています。しかし、それらの有益な情報はタイムラインに埋もれやすく、後から体系的に検索してストックすることが困難という課題があります。

本プロジェクトでは、コアプレイヤーや検証勢、TA走者が持つ「ニッチで付加価値の高い知識」を可視化し、分類・ストック・深掘りできる「ナレッジベース型のWEB掲示板アプリケーション」を開発します。

### **1.2 ターゲットユーザー**

* **コアプレイヤー / 検証勢 / TA走者**: 自身の見つけた小技や立ち回り、TAのルートを正確かつ詳細に共有したいユーザー。  
* **プレイスキル向上を目指すプレイヤー**: 武器種やモンスターに特化した深い攻略情報を求めており、実践中に手元のスマホで確認したり、PCで動画をスロー検証したいユーザー。

### **1.3 アプリケーションの特長**

1. **リッチなメディア表現**: 視覚的な検証を容易にするため、テキストに加えて各種動画・SNS埋め込みに対応。  
2. **高い検索性**: 「武器種」「モンスター」「目的」などのマルチタグによる高度なフィルタリング。  
3. **質の高い非同期議論**: リアルタイム性を排除し、1つの小技に対して時間をかけて深い検証が行えるスレッド式コミュニケーション。  
4. **完全レスポンシブ**: ゲームプレイ中のスマートフォン利用、および大画面PCでの研究用途の両方をカバー。

## **2\. システム構成・動作環境**

### **2.1 対象デバイス**

* **スマートフォン**: 実戦中に手元でサクッと確認できるレスポンシブUI。  
* **PC / タブレット**: 動画のスロー再生や、複数スレッドの閲覧に適した2カラムまたはマルチカラムUI。

### **2.2 システムアーキテクチャ想定**

* **フロントエンド**: HTML5 / CSS3 (Tailwind CSS) / React もしくは Next.js（完全レスポンシブ対応）  
* **バックエンド / データベース**: REST API、RDB もしくは NoSQL（Firebase Firestore等。リアルタイム通信用ソケット等は不要）

## **3\. 機能要件**

機能実装は、開発スケジュールと確実な動作確認を考慮し、フェーズを2段階に分けて定義します。本開発（卒業制作等）の初期マイルストーンとしては「フェーズ1（MVP：最小限の必須機能）」の確実な完成をターゲットとします。

### **3.1 フェーズ1：MVP（最小限の必須機能）**

#### **① 投稿・メディア共有機能**

* **新規投稿作成**: タイトル、本文の入力。  
* **リッチメディア埋め込み**:  
  * YouTube動画のURL埋め込み表示。  
  * X（旧Twitter）の個別ポスト（投稿）の埋め込み表示。  
  * 短尺のループ再生用GIFアニメ、または動画データのアップロード対応。  
* **マルチタグ設定**:  
  * **武器種タグ**（大剣、太刀、片手剣、双剣、ハンマー、狩猟笛、ランス、ガンランス、スラッシュアックス、チャージアックス、操虫棍、ライトボウガン、ヘビィボウガン、弓の14種）から複数選択。  
  * **モンスタータグ**（主要モンスター名）の選択。  
  * **目的・ジャンルタグ**（「TA」「立ち回り」「装備構成」「小技・バグ検証」等）の選択。

#### **② 検索・閲覧機能**

* **マルチタグ検索**: 武器種、モンスター、目的タグを組み合わせたAND/OR絞り込み検索。  
* **投稿詳細表示**: リッチメディアを含む投稿内容を、PC・スマホどちらでも崩れない形で表示。

#### **③ コミュニケーション機能**

* **個別ディスカッションスレッド（非同期）**:  
  * 各小技投稿の下部に、階層構造（ツリー構造）を持たせたコメントスレッドを設置。  
  * 特定の主張に対して、検証結果や補足を「個別リプライ」として議論可能。  
  * ※WebSocket等を用いたリアルタイム同期は行わず、リロードや非同期通信（ページネーション、ポーリング）による更新とする。

#### **④ アカウント・マイページ機能**

* **プレイスタイル可視化プロフィール**:  
  * 新規登録時に「メイン武器種（複数選択可）」と「プレイスタイル（TA勢 / エンジョイ勢 / 検証勢 / その他）」を選択必須とする。  
  * 投稿者やコメント送信者の名前の横に、設定されたメイン武器種のアイコンやプレイスタイルバッジを表示し、情報の説得力・信頼性を一目で判別できるようにする。  
* **ブックマーク（お気に入り保存）機能**:  
  * ユーザーは気になった投稿・スレッドをブックマークに登録できる。  
  * マイページからブックマークした一覧へいつでも即座にアクセス可能。

### **3.2 フェーズ2：将来的な拡張機能**

初期フェーズが順調に完了した場合、または開発期間に猶予がある場合に実装する追加要件です。

#### **① セキュリティ・モデレーション機能**

* **通報ボタンの設置**: 不適切なコンテンツ、チート、マウンティング、荒らし行為のある投稿やコメントを運営に通報する機能。  
* **管理者用ダッシュボード（管理画面）**:  
  * 通報された投稿・コメントの一覧表示、確認。  
  * 不適切と判断したコンテンツのワンクリック非表示、削除機能。  
  * 悪質なユーザーをシステムからBAN（利用停止）する権限機能。

#### **② 信頼性向上システム**

* **運営公認バッジ**: 有名な配信者や著名なプロハンター、実績のある検証勢に対して、運営管理者が「公認バッジ」を手動付与できるシステム。なりすましを防止し、情報の確実性を担保する。

## **4\. 非機能要件**

### **4.1 UI/UXデザイン**

* **ゲーム的世界観の構築**: モンスターハンターの重厚感あるUIデザインを意識したダークテーマ配色（黒・金・茶・革の質感を想起させるパレットなど）を推奨。  
* **直感的な操作性**:  
  * スマホでの親指タップを意識した、十分なサイズ（最小 44x44px）のタッチターゲットの確保。  
  * 動画要素がページ幅からはみ出さない可変フレックスボックス・レイアウト。

### **4.2 パフォーマンス・セキュリティ**

* **画像・動画の最適化**: 投稿された大容量のGIFアニメや動画による表示速度遅延を防ぐため、遅延読み込み（Lazy Loading）の実装。  
* **不正アクセス防止**: 認証機能（Firebase Auth等）による、非ログイン状態での「投稿・コメント・ブックマーク機能」の書き込み制限。
